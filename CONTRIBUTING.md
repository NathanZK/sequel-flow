# Contributing

Sequel Flow is currently a small design/prototype project. Contributions
should keep the workflow project-agnostic and lightweight.

- Discuss a change to the core workflow or story-mode contracts before
  introducing a new role, gate, or required artifact.
- Prefer concise explanations and examples over implementation detail.
- Do not add agents, scripts, automation, schemas, application code, or a
  license without an agreed project direction.
- For documentation changes, explain the problem the change addresses and
  keep the stage responsibilities and mode constraints consistent.
